<h1 align="center">光 Hikari</h1>
<p align="center"><i>Your photos, in their best light.</i></p>

Hikari is a photo library and non-destructive raw developer by CuteClaudia, for **Windows**,
**Linux** and **Android** phones and tablets. Download the latest version from
**[Releases](https://github.com/cuteclaudia/hikari-releases/releases/latest)**.

| Platform | Download | How to install |
|---|---|---|
| Windows 10 / 11 (64-bit) | `hikari-<version>-windows-x64-setup.exe` | Run it. If Windows shows "Windows protected your PC", choose **More info → Run anyway** (or right-click the file → Properties → **Unblock**). |
| Windows, no install | `hikari-<version>-windows-x64-portable.zip` | Unzip and run `hikari.exe`. |
| Linux (any distro) | `hikari-<version>-linux-x86_64.AppImage` | Make it executable, then run it. |
| Ubuntu, Debian, Mint | `hikari-<version>-linux-x86_64.deb` | Open it with your software centre, or `sudo apt install ./hikari-*.deb`. |
| Fedora, openSUSE | `hikari-<version>-linux-x86_64.rpm` | `sudo dnf install ./hikari-*.rpm` |
| Android 8+ (phones and tablets) | `hikari-<version>-android-arm64.apk` | Open it on the device and allow installing from this source. Best on tablets; phones work best in landscape. |

Each release lists `SHA256SUMS.txt` to check your download. Installed copies offer new versions
when they're published here.

Hikari is based on [LightCraft](https://github.com/storytold/lightcraft) by the ArtCraft Team and
the LightCraft contributors, and is licensed MIT OR Apache-2.0.
